# final_binome_mobile

Application Flutter **Binome** avec trois espaces:
- Locataire
- Propriétaire
- Administratif

## Fonctionnalités principales
- Interfaces complètes demandées pour chaque rôle
- Design business premium (cartes, gradients, métriques)
- Mode clair par défaut + mode sombre pour tous
- Persistance locale avec `shared_preferences` (pas de cloud)
- Intégration OpenStreetMap (`flutter_map`)
- Plusieurs visuels d'annonces avec images professionnelles

## Lancer le projet
1. Installer Flutter SDK
2. Exécuter:
   ```bash
   flutter pub get
   flutter run
   ```
